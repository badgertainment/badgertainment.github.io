About Badgertainment

A small indie studio making ready-to-use assets for farming, life-sim, cozy RPG, casual and retro horror games.

Every icon pack sticks to one consistent cartoon style, so icons from different packs sit nicely together in the same inventory or shop screen. Packs come with clear file names, sprite sheets and data files, so you can drop them straight into your own item database, in any engine.

In every icon pack

  • Transparent PNG in 512, 256, 128 and 64 px
  • Silhouettes for locked or undiscovered items
  • Sprite sheets with JSON and CSV rects
  • items.csv with clear file prefixes
  • Commercial use, no attribution needed
