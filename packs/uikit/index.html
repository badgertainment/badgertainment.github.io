Cozy UI Kit

128 cozy UI pieces: buttons with 4 states, panels, frames, bars, toggles and 50 UI icons. 9-slice ready.

128 cozy UI elements plus 72 button state sprites (buttons, panels, frames, bars, toggles, cursors, badges and 50 UI icons) for cozy, farming, life-sim, crafting and casual mobile games. Everything shares one warm wood-and-pastel style with bold outlines, so your menus, HUD, inventory and shop screens look like one set.

At a glance

  • 128 UI elements, transparent PNG
  • 18 buttons (6 colors x 3 shapes) in 4 states each: normal, hover, pressed, disabled
  • UI_Tight folder: panels, buttons, frames, bars and dividers cropped tight for 9-slice scaling
  • slices.json with suggested 9-slice borders for every sliceable sprite (for any sprite editor or Godot NinePatchRect)
  • 4 sizes: 512, 256, 128 and 64 px
  • Dark silhouette versions (512/256) for locked or undiscovered items
  • Sprite sheets per size with JSON and CSV frame data
  • items.csv with file name, display name and category

What's inside

  • 18 buttons (+ hover/pressed/disabled states): pill cream, pill mint, pill rose, rect cream, rect mint, rect rose, square cream and more
  • 15 panels & dialogs: cream dialog, notebook, peach, scroll, sky, stitched, thought and more
  • 12 frames & slots: avatar flowers, card, gold ornate, hotbar, leafy, photo, portrait round and more
  • 12 bars & sliders: frame wood, health, hearts, loading, mana, scroll thumb, scroll track and more
  • 6 toggles & checkboxes: check empty, check on, off, on, radio empty, radio on and more
  • 50 ui icons: arrow down, camera, craft, help, mail, plus, settings and more
  • 3 cursors: grab, hand, pointer and more
  • 8 badges & medals: dot, heart, medal bronze, medal gold, medal silver, ribbon new, star and more
  • 4 dividers: flowers, ribbon, vine, wood and more

Great for

  • Inventory, shop, crafting and collection screens
  • Quest rewards, loot drops and achievements
  • Godot, GameMaker, Unreal, RPG Maker, web, mobile and any other engine

AI disclosure

The icon artwork was generated with FLUX.2 Klein 4B (Apache 2.0) running locally, then curated, cleaned up (background removal, trimming, centering, resizing) and quality-checked. Defective icons were regenerated.
